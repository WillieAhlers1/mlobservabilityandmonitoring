Model Onboarding Guide

Step 1: Provide basic model information including name, type, and associated project.

Step 2: Configure deployment details like the prediction endpoint and model version.

Step 3: Set up monitoring parameters including performance thresholds and drift detection methods.

Step 4: Configure alerting channels for automated notifications when issues are detected.

After onboarding, the model will be monitored automatically and appear in the Cockpit.

Prerequisites
  • Model deployed and serving predictions
  • Prediction endpoint accessible
  • Ground truth pipeline configured
  • Feature schema documented
  • Baseline performance metrics available
Agent Onboarding Guide

Step 1: Provide agent identity — name, framework, LLM backbone, and project.

Step 2: Configure deployment details including the agent endpoint and version.

Step 3: Register external tools and any ML models the agent consumes.

Step 4: Set quality thresholds for task completion, groundedness, safety, cost, and latency.

Step 5: Configure compliance requirements (HIPAA, PHI handling).

Step 6: Set up alerting channels for automated notifications.

After onboarding, the agent will be monitored for groundedness, safety, cost, and task success.

Prerequisites
  • Agent deployed and responding to requests
  • Agent endpoint accessible
  • Tool integrations configured and tested
  • LLM API keys provisioned
  • Baseline evaluation completed (task completion & groundedness)
  • Compliance review completed (if handling PHI/PII)
